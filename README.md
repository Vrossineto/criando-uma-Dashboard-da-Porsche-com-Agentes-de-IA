# Porsche Sales Intelligence Dashboard

Dashboard interativa de análise de vendas de veículos Porsche, desenvolvida em **HTML, CSS e JavaScript**, com foco em uma experiência visual elegante, minimalista e refinada.

O projeto transforma dados de vendas em indicadores e insights comerciais de fácil interpretação.

## Principais recursos

### Filtros interativos

- **Modelo Porsche**
- **Model Year**
- **City**
- **Pay Method**

Os filtros são combináveis e atualizam os indicadores e visualizações em tempo real.

### KPIs

- Total de veículos vendidos
- Receita total
- Ticket médio
- Modelo mais vendido
- Ano-modelo de maior volume
- Cidade com maior número de vendas
- Meio de pagamento predominante

### Análises de negócio

A dashboard responde perguntas como:

1. Quais são os principais modelos vendidos por cidade?
2. Qual ano-modelo apresentou maior volume de vendas?
3. Quais carros são mais populares em cada cidade?
4. Qual modelo lidera as vendas?
5. Quais cidades concentram maior volume de vendas?
6. Qual meio de pagamento possui maior participação?

## Insights

### Modelo × Cidade

Identifica quais modelos possuem maior presença em cada cidade e permite observar diferenças de preferência regional.

### Model Year

Permite analisar a distribuição das vendas por ano-modelo e identificar os anos com maior saída.

### Popularidade por cidade

O ranking de modelos por cidade evidencia os veículos com maior demanda local.

### Performance comercial

Os principais indicadores permitem acompanhar rapidamente:

```text
Vendas
Receita
Ticket médio
Modelo líder
Ano-modelo líder
Cidade líder
```

## Objetivo

Demonstrar como transformar uma base de dados comercial em uma **dashboard executiva interativa**, combinando:

**Dados → KPIs → Visualização → Insights → Decisão**

O projeto busca facilitar a identificação de padrões de vendas por **modelo, cidade e ano**.
